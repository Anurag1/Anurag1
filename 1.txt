🧠 3. Orchestrator (Intelligence Layer)

🔹 Planner + Router (orchestrator/app/planner.py)

def plan(task: dict):
    # simple rule-based planning (extend later with LLM)
    if "code" in task["type"]:
        return ["coding_agent"]
    elif "search" in task["type"]:
        return ["retrieval_agent"]
    return ["reasoning_agent"]

🔹 Executor (orchestrator/app/executor.py)

import requests
AGENTS = {
    "coding_agent": "http://compute:9001/code",
    "retrieval_agent": "http://compute:9002/search",
    "reasoning_agent": "http://compute:9003/reason"
}
def execute(plan, task):
    results = []
    for step in plan:
        res = requests.post(AGENTS[step], json=task)
        results.append(res.json())
    return results

🔹 Main Service (orchestrator/app/main.py)

from fastapi import FastAPI
from planner import plan
from executor import execute
app = FastAPI()
@app.post("/execute")
def run(task: dict):
    steps = plan(task)
    result = execute(steps, task)
    return {"steps": steps, "result": result}

💾 4. Memory Layer

🔹 Memory Service (memory/memory_service.py)

from sentence_transformers import SentenceTransformer
import faiss
import numpy as np
model = SentenceTransformer('all-MiniLM-L6-v2')
index = faiss.IndexFlatL2(384)
memory_store = []
def store(text: str):
    emb = model.encode([text])
    index.add(np.array(emb))
    memory_store.append(text)
def retrieve(query: str, k=3):
    emb = model.encode([query])
    D, I = index.search(np.array(emb), k)
    return [memory_store[i] for i in I[0]]

🧠 10. System Behavior (End-to-End Flow)

1. Request → Gateway
2. Gateway → Orchestrator
3. Orchestrator:
    * Plans task
    * Routes to agents
4. Compute workers execute
5. Memory layer stores + retrieves context
6. Response returned
